# SAT求解器 - 基于DPLL算法

本项目实现了一个基于DPLL算法的高效SAT求解器，支持CNF格式的布尔可满足性问题求解，并集成了数独游戏求解功能。

## 功能特性

### 核心功能
1. **输入输出功能**
   - 支持标准DIMACS CNF格式文件读取
   - 提供详细的求解结果输出
   - 支持结果保存到文件

2. **公式解析与验证**
   - 完整的CNF文件解析功能
   - 内部数据结构建立和管理
   - 解析正确性验证（可选显示公式内容）

3. **DPLL算法实现**
   - 完整的DPLL求解过程
   - 单元传播(Unit Propagation)
   - 回溯搜索
   - 自定义数据结构（不使用STL容器）

4. **性能测量**
   - 精确的时间统计（毫秒级）
   - 决策次数统计
   - 冲突次数统计
   - 传播次数统计

5. **算法优化**
   - VSIDS变量选择启发式
   - 性能对比测试
   - 优化率计算

6. **SAT应用 - 数独求解**
   - 数独到SAT问题的转换
   - 交互式数独游戏
   - 多种输入方式支持

## 数据结构设计

### 核心数据结构
- **Literal**: 文字结构，包含变量编号和符号
- **Clause**: 子句结构，包含文字数组
- **CNFFormula**: CNF公式结构，包含子句数组
- **DynamicArray**: 自定义动态数组模板类

### 存储优化
- 使用自定义动态数组避免STL依赖
- 紧凑的内存布局
- 高效的访问模式

## DPLL算法实现

### 核心流程
1. **单元传播**: 处理单元子句，进行强制赋值
2. **变量选择**: 选择分支变量（支持启发式）
3. **递归搜索**: 尝试不同的变量赋值
4. **回溯**: 遇到冲突时撤销决策

### 优化策略
- **VSIDS启发式**: 选择在最多未满足子句中出现的变量
- **冲突分析**: 统计冲突信息用于优化

## 性能分析

### 优化效果
优化率计算公式：`[(t-to)/t]*100%`
- t: 基础DPLL执行时间
- to: 优化DPLL执行时间

### 统计信息
- 求解时间（毫秒）
- 决策次数
- 冲突次数  
- 传播次数

## 数独求解

### SAT转换
数独问题转换为SAT问题的约束：
1. 每个格子有且仅有一个数字
2. 每行每个数字恰好出现一次
3. 每列每个数字恰好出现一次
4. 每个3x3子网格每个数字恰好出现一次

### 变量编码
- 729个布尔变量 (9×9×9)
- 变量x_{r,c,n}表示第r行第c列填入数字n
